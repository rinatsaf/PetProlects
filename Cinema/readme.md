# Cinema

Backend-проект для системы кинотеатра на `ASP.NET Core`. Репозиторий показывает серверную архитектуру для работы с каталогом фильмов, сеансами, заказами, билетами, оплатой и временным резервированием мест.

## Что показывает проект

- слоистую архитектуру `Api / Application / Domain / Infrastructure`;
- REST API для фильмов, жанров, залов, сеансов, заказов и платежей;
- ролевую аутентификацию и авторизацию;
- работу с `PostgreSQL` через `EF Core`;
- временный hold мест через `Redis`;
- интеграцию с `YooKassa`;
- логирование и инфраструктуру для локального запуска.

## Технологии

- `.NET 9`
- `ASP.NET Core Web API`
- `Entity Framework Core`
- `PostgreSQL`
- `Redis`
- `AutoMapper`
- `FluentValidation`
- `Serilog`
- `Swagger`
- `Docker Compose`

## Архитектура

- `Api` — контроллеры, middleware, hosted services, конфигурация HTTP pipeline.
- `Application` — сервисы, DTO, валидация, маппинг и прикладная логика.
- `Domain` — сущности и бизнес-модель.
- `Infrastructure` — доступ к данным, Redis, внешние интеграции и технические сервисы.

Такое разделение упрощает поддержку, тестирование и развитие функциональности без смешивания бизнес-логики с инфраструктурой.

## Реализованные сценарии

- регистрация и вход пользователя;
- управление фильмами, жанрами, залами и сеансами;
- создание заказа с резервированием мест;
- отмена просроченных заказов в фоне;
- создание платежа и обработка webhook от YooKassa;
- перевод заказа и билетов в финальное состояние после оплаты.

## Инфраструктура запуска

В проекте есть `docker-compose.yml` для локального подъёма:

- `PostgreSQL`
- `Redis`
- `Adminer`
- `ngrok` для тестирования внешнего webhook-сценария
